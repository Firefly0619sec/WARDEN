# 语言包说明（B1 / B2）

WARDEN 的界面文案单独放在语言包里，方便加语言 ✓

## 现有语言包

| 文件 | 语言 | 状态 |
|---|---|---|
| `tools/settings/zh-Hans.txt` | 简体中文 | 完整 ✓（默认） |
| `tools/settings/zh-Hant.txt` | 繁体中文 | 由简体自动转换 ✓（B2） |
| `tools/help/zh-Hans.txt` | 简体中文（帮助工具） | 完整 ✓ |
| `tools/help/zh-Hant.txt` | 繁体中文 | 自动转换 ✓ |

## 怎么切语言

语言包按文件名加载 → 直接换文件即可：

```powershell
cd tools\settings
Copy-Item zh-Hant.txt zh-Hans.txt -Force   # 切成繁体
Copy-Item zh-Hant.txt.bak zh-Hans.txt -Force  # 换回来
```

  要做的时候：复制 zh-Hans.txt 成 en.txt，把值改成英文即可 ✓）

## 加新语言

1. 复制 `zh-Hans.txt` → `xx.txt`
2. 只改 `=` 右边的内容（左边是键，代码里用的，别动 ✗）
3. 把 `xx.txt` 复制成 `zh-Hans.txt` 就是切换 ✓
