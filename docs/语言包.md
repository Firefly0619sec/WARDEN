## 现在有六个语言包

| 文件 | 语言 | 用词约定 |
| --- | --- | --- |
| `lang\zh-Hans.txt` | 简体中文（**主档** ✓） | 原文基准 ✓ 其它包都从它派生 ✓ |
| `lang\zh-TW.txt` | 繁體中文（臺灣） | 「臺灣」「處理程序」「資料夾」 |
| `lang\zh-HK.txt` | 繁體中文（香港） | 「程序」「資料夾」 |
| `lang\zh-MO.txt` | 繁體中文（澳門） | 同香港 ✓ |
| `lang\en-GB.txt` | English (UK) | licence / colour / behaviour |
| `lang\en-US.txt` | English (US) | license / color / behavior |

## 文件格式

```
[meta]       版本、语言名等元信息
[ui]         interface 文案（key = 语义化标识，如 set.tab.lang ✓）
[log.tag]    日志标签
[log.rule]   规则说明文案
[text]       ★ 以【简体中文原文】作为 key ✗ 这是历史设计 ✓
```

* 解析规则：按**第一个 `=`** 切开 ✓ 所以 **key 里不能有 `=`** ✗
  （曾经踩过：`★ 勾选 = 启用该规则` 被从等号处切断 → 整条翻译失效 ✓ 已改文案 ✓）
* `[text]` 段的 key 保持简体 ✓ 值才是译文 ✓
* 每个语言包都必须与主档的 key 集合一致 ✓（缺 key 会显示成原文 ✓）

## 新增/修改语言包的正确流程

1. 改 `lang\zh-Hans.txt`（加 key ✓ 值就是简体原文 ✓）
2. 同步其它五个包：`[ui]/[log.*]` 段用各自的译文 ✓ `[text]` 段用 key 的对应译文 ✓
3. 繁体包可以用 OpenCC 从简体派生 ✓ 但要人工过一遍用词约定 ✓
   （臺灣包用「臺灣」✗ 不用「台灣」✓）
4. 跑一次校验：本文档所在仓库的 `诊断\tools` 里有 key 比对脚本 ✓
5. 设置界面还会去扫 `%LOCALAPPDATA%\WARDEN\lang` ✓ 以及 exe 同级的 `lang\` 与 `data\lang\` ✓
   所以便携版把这些目录带上就能换语言 ✓

## 主程序与设置界面怎么读

* 主程序 `WARDEN.L.T("原文")` ✓（轻量表 ✓ 名字与 ConsentDialog.L 冲突过 ✗ 故改名 ✓）
* 设置界面 `Lang.Tr("原文")` ✓（WinForms 版 ✓）
* 共同点：都从 `WARDEN.json` 的 `"lang"` 读当前语言 ✓ 找不到就回落简体 ✓
