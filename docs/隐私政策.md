# 隐私政策（WARDEN）

**一句话：WARDEN 不收集、不存储、不传输你的任何个人信息 ✓**

## 它会不会联网

| 组件 | 联网情况 |
| --- | --- |
| WARDEN 主程序 | ★ **完全不联网** ✓（Native AOT 单文件，没有任何网络代码 ✗） |
| 设置 / 日志查看 / 帮助 / 卸载 | ★ 完全不联网 ✓ |
| 更新器（WARDEN-Updater） | 只在你点「检查更新」时访问 GitHub 一次 ✓ |
| 在线安装器 | 只在你要安装时访问 GitHub 一次 ✓ |

## 它会产生什么数据

全部在**你自己的电脑上** ✓，都在 `%LOCALAPPDATA%\WARDEN\`（便携模式在程序的 `data\` ✓）：

| 文件 | 内容 | 会不会外发 |
| --- | --- | --- |
| `WARDEN.json` | 你的规则与设置 | 不会 ✓ 除非你自己发出去 |
| `WARDEN.log` | 它做了什么（含窗口标题、进程名） | 不会 ✓ |
| `EMERGENCY.log` | 被攻击时的证据（进程名、时间） | 不会 ✓ |
| `TAMPER.log` | 被干扰的记录 | 不会 ✓ |

★ 你要卸载时可以勾选"连配置与日志一起删"✓ 不勾就保留（方便你留证据 ✓）

## 什么时候数据才会离开你的电脑

只有一种情况：**你自己主动**用「上报证据 / 反馈问题」把内容发出去 ✓
而且：

* 发送前会**先把路径里的用户名打码** ✓
* 会让你**先看清要发什么**（预览 ✓）
* 传输方式**默认不选** = 什么也不发 ✗
* 可选明文（贴到 GitHub issue）或 PGP 加密（只有作者能解 ✓）

## 第三方

* 本项目**没有任何第三方依赖** ✓（只用 .NET 运行时与 Windows API ✓）
* 没有统计 SDK、没有广告 SDK、没有崩溃上报服务 ✓
* 代码签名由 **SignPath Foundation** 提供；签名过程只处理构建产物，不涉及你的数据 ✓
