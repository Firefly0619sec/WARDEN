# 下载 WARDEN

> ★ 本项目的 Windows 安装包由 **SignPath Foundation** 提供免费的代码签名服务 ✓
> 也就是说：安装包上的数字签名来自 SignPath Foundation，而非个人自签 ✗
> 这让 Windows 能验证"文件确实来自本项目、且没有被改过" ✓

## 最新版本

**Beta 2（0.1.0-beta.2）**

| 你要的东西 | 去哪拿 |
| --- | --- |
| 离线安装包（推荐 ✓ 不需要网络） | [Releases 页面](https://github.com/Firefly0619sec/WARDEN/releases) → `WARDEN-Setup.exe` |
| 在线安装器（约 5 MB ✓ 拉最新版） | 同一页面 → `WARDEN-Online-Setup.exe` |
| 校验值 | 同一页面 → `SHA256SUMS.txt`（★ 下载后对一下 ✗） |

## 装之前建议做两件事

1. **对哈希**：把 `SHA256SUMS.txt` 里的值与 `Get-FileHash 文件 -Algorithm SHA256` 比一比 ✓
2. **看签名**：右键安装包 → 属性 → 数字签名 → 签名者应为 **SignPath Foundation** ✓

## 其它下载方式

* 源码：`git clone https://github.com/Firefly0619sec/WARDEN.git` 然后跑 `build.ps1` ✓
* 只想看它能不能用：仓库里的 `WARDEN-RedTeam.exe` 会弹一批"关不掉"的窗口 ✓
