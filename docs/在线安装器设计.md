> 用户指正（原话大意）：
> "在线安装器那个 GUI 你都设计错了，我要的是离线下载器的那种。
>  而且我原本的设计里面，这玩意是要看用户的环境的 ——
>  如果用户的环境有问题的话，它是不会贸然安装的，
>  它会帮忙把环境给安上去，并且提示用户，更具人文关怀。"

---

## 一、我上一版错在哪（认下来 ✓）

```
✗ 错法：做成一个"只有进度条的小窗"✗（标题 + 进度 + 三个按钮 ✓）
✗ 观感：跟离线安装器 WARDEN-Setup 完全不是一回事 ✗
✗ 最要紧的：**没有环境检测** ✗
   直接就去下载安装了 ✗ —— 环境不满足的用户会装出一个打不开的程序 ✗
   那正是我们最不想看到的事（"装完打不开"= 普通人眼里的"这软件是坏的"✗）
```

## 二、正确设计：两件事

### ① 界面 = 离线安装器的同款向导 ✓

```
┌────────────────────────────────────────────────────┐
│  ███ 蓝色标题区（同 WARDEN-Setup 的那个蓝）        │
│  WARDEN 在线安装                                    │
│  自动获取最新版 · 装之前先替你把环境检查一遍 ✓      │
├────────────────────────────────────────────────────┤
│  第 1 步 / 3：环境检测        ← 页标题（粗体）      │
│                                                    │
│   态 页面内容（每一项前面有 ✓ / ✗ / ⏳ ）           │
│                                                    │
├────────────────────────────────────────────────────┤
│              [上一步] [下一步 / 开始安装] [取消]    │
└────────────────────────────────────────────────────┘
```

* 蓝色标题区：**自绘**（在 WM_PAINT 里填色 + 写字 ✓）
  ★ 不再用 `WM_CTLCOLORSTATIC` 返画刷那套 ✗（AOT 下 fail-fast ✗ 已踩过 ✓）
* 底部按钮与页脚布局跟离线安装器一致 ✓
* 三步：**环境检测 → 下载 → 校验并安装** ✓

### ② 第一步真的检查环境，不满足就不装 ✓

要查的（每项都要能给出"人话 + 怎么办"✓）：

| 检查项 | 怎么查 | 不满足时怎么办（★ 关键） |
| --- | --- | --- |
| Windows 版本 | `RtlGetVersion` | 说清需要 Win10 1607 以上 ✓ 并给升级指引链接 ✓ |
| **VC++ 运行库**（Native AOT 的硬依赖 ✗） | 试加载 `vcruntime140.dll` / 查 System32 | ★ **一键帮它装上**（下载微软官方 vc_redist.x64.exe 并静默安装 ✓） |
| 磁盘空间 | `GetDiskFreeSpaceExW` | 说清"还差多少 MB"✓ 并建议清理方向 ✓ |
| 能不能往临时目录写 | 真写一个临时文件 ✓ | 说明可能是安全软件拦了 ✓ 建议加白名单 ✓ |
| 网络能不能到 GitHub | 试探 API（走代理 ✓） | ★ 提供三种方案：走代理 / 手动下载 / 稍后再试 ✓ |
| 是否已被签名保护 | （F2 通过后）提示签名状态 ✓ | 说明"还没签名，请核对 SHA256"✓ |

★ 三条原则（写给实现的人）：

1. **不满足就不装** ✗ —— 绝不"先装了再说" ✗
2. **能替用户做的就替他做掉** ✓（VC++ 运行库这种，一键装好 ✓）
   做不了的说清"为什么"和"你可以怎么办"✓ 不甩错误码 ✓
3. **语气**：把用户当普通人 ✗ 不出现"依赖缺失 / error code"这类词 ✓

## 三、界面文案示例（语气要对 ✓）

```
环境检测不通过时：

  ✗ 你的电脑还缺一个小零件（VC++ 运行库）
     WARDEN 和它带的小工具需要它才能启动 ✓
     这不是你的错，很多新装的 Windows 都缺这个 ✓
     [ 帮我装好 ]        [ 我自己去下载 ]

  ✗ 网络连不上 GitHub
     国内网络经常连不上 ✓ 没关系，有两条路：
     [ 用我的代理试试 ]  [ 手动下载安装包 ]
```

## 四、实现约束（技术上的硬要求 ✓）

```
· 必须是【原生 AOT】✗ 不能用 WinForms（那样 47 MB ✗ 与离线包一样大 ✗）
· 窗口标题区自绘 ✓ 不用 WM_CTLCOLORSTATIC ✗（AOT fail-fast 已踩 ✓）
· 用系统 curl.exe 做网络请求 ✓（省掉 HttpClient 约 2 MB ✓）
· 体积目标：3 MB 以内 ✓（当前 2.9 MB ✓ 还能再加一点环境检测逻辑 ✓）
· 环境检测逻辑可以参考离线安装器里的 EnvCheck.cs ✓（那份是 30 KB 的成熟实现 ✓）
```
