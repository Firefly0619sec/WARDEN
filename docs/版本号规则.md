# 版本号规则（用户 2026-10-11 说明）

```
x . y . z
│   │   └── 这个 Beta 版的第几次改版
│   └────── 第几个 Beta 版（在它前面那个正式版之后）
└────────── 第几个正式版（现在还没有正式版 → 0）
```

## 当前所有版本都是 Beta ✓

| 版本 | 含义 |
| --- | --- |
| `0.1.0-beta.2` | 早期命名，等价于「Beta 1 的第 2 次改版」✗ 已被下面的写法取代 |
| `0.2.1` | 还没有正式版（0）· **Beta 2** · 第 1 次改版 |
| `0.2.2` | 还没有正式版（0）· Beta 2 · 第 2 次改版 |
| `0.2.3` | 还没有正式版（0）· Beta 2 · 第 3 次改版 |
| `0.2.4` | 还没有正式版（0）· Beta 2 · 第 4 次改版 ← 当前 |
| `1.0.0` | 将来第一个正式版 ✓ |

## 命名规矩

* 正式版：`x.0.0`（例如第一个正式版 = `1.0.0` ✓）
* Beta：`x.y.z`，其中 y≥1，z 从 1 开始递增 ✓
* **不再用 `-beta.N` 后缀** ✗（`x.y.z` 已经把 Beta 号说清了 ✓）
* Release 标题写法：`WARDEN 0.2.4（Beta 2 · 第 4 次改版）` ✓
* 正式版发布时：`WARDEN 1.0.0（正式版）` ✓ 并把 `-prerelease` 去掉 ✗
