**Short description (English)**

```
WARDEN is a free, open-source Windows utility that identifies and stops
intrusive popups by scoring window behaviour instead of matching titles or
ad signatures. It runs entirely offline, needs no account, never uploads
anything, and never hard-kills processes that carry a valid signature or are
on the user's whitelist. It ships with six interface languages and is built
as a Native AOT single executable.
```

**Why do you need code signing?**

```
Without a signature, Windows SmartScreen shows "Unknown publisher" for every
download, which is a real barrier for the non-technical users this tool is
aimed at. Because WARDEN reads window information and ends processes, an
unsigned binary also looks exactly like the adware it is meant to stop, so
antivirus products flag it and users cannot easily tell the difference.
A signature from a recognised CA lets users verify that the file really comes
from this project and has not been tampered with.
```

**Do you build in CI?**

```
Yes — GitHub Actions (.github/workflows/build.yml). We intend to use the
official SignPath GitHub Action and will not sign locally.
```

**Is the project commercial?**

```
No. WARDEN is free software under AGPL-3.0-or-later. There is no paid tier,
no advertising, no telemetry, and no data collection of any kind.
```
