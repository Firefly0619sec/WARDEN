## 第 4 页 · 项目详情与你的账号

### Description\*

> *A short paragraph describing your project and its purpose. **Avoid listing version-specific
> features or dependencies.***
> ★ 别写版本号、别写依赖 ✗ 我写的这段是行为与设计层面的 ✓

```
WARDEN is a free, open-source Windows utility that identifies and suppresses intrusive
popups. Instead of matching window titles or shipping an ad-signature list that goes stale,
it scores observable behaviour: how often a window is created, whether it repeatedly steals
focus, whether it contains input boxes or child controls, whether it is a small floating
panel, whether it churns its title, and whether it returns after being closed. Only windows
above a user-controlled threshold are acted on, and the escalation is deliberately gradual -
ask the window to close, hide it, and only then consider force-killing it if the user has
allowed that. Processes carrying a valid code signature, or listed on the user's whitelist,
are never hard-killed. The program runs completely offline, needs no account, collects
nothing, writes an auditable local log of everything it does, and keeps evidence on the
user's own machine. It ships with six interface languages and is built as a native
single-file executable.
```

### Reputation\*

> *Provide links or information showing that your project is widely used or trusted. Examples
> include media coverage, blog posts, download statistics, GitHub insights, or community
> discussions.*
> ★ 这条最容易被拒 ✗ 我们项目太新 ✗ 所以我写得**诚实**：
>   不编造用户量 ✓ 而是列可验证的事实（GPG 签名提交 · CI · 威胁模型文档 ·
>   行为测试套件里"白名单不强杀"的自动断言 ✓）

```
WARDEN is a new project - it reached public beta in October 2026, so there is no media
coverage or download history yet. What can be verified today:

* Public repository with full source, build script and CI:
  https://github.com/Firefly0619sec/WARDEN
* Every commit is GPG-signed; the repository history is public and auditable.
* A GitHub Actions pipeline builds every push (.github/workflows/build.yml).
* The project documents its threat model, safety design and licence reasoning in-tree
  (docs/设计说明.md, docs/许可与合规.md).
* It has an automated behavioural test suite that drives a purpose-built rogue-window
  simulator and asserts, among other things, that whitelisted processes are never
  force-killed and that out-of-scope processes are never touched.
* Usage so far is the maintainer's own machines plus a small group of testers; feedback is
  collected through the repository's issue templates.

We are applying at this early stage deliberately: unsigned binaries are exactly the problem
this tool exists to solve, and SmartScreen currently warns on every download.
```
