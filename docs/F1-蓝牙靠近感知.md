# F1 蓝牙靠近感知 —— ★ 结论：不做（2026-10-14 决定）

> 决策人：用户。原话大意：
> "没必要往那个开源程序加蓝牙的，毕竟它要一直拦弹窗，
>  那个弹窗人走了又不是不会弹。"

## 为什么不做了（这个理由很硬 ✓）

```
WARDEN 的职责是【一直拦弹窗】✗
人走了，弹窗照样会弹 —— 而且那时候更需要它拦 ✓
  · 人在：弹窗烦人 ✓ 要拦
  · 人走：弹窗照样弹（还可能更放肆 ✓）更要拦 ✓
→ "人走了就暂停守护"恰好把最需要它的时候关掉了 ✗
  这个设计与产品目标相反 ✗ 所以不做 ✓
```

## 如果以后真要做，正确形态应该是

```
不是"暂停守护"✗ 而是"改变处置策略"✓

  · 人不在 → 照样拦，但【不弹询问】（没人回答只会挂着 ✗）
              把处置压到"隐藏+记录"这一档 ✓ 等你回来看日志 ✓
```
